Warunki korzystania – MSF Assistant

MSF Assistant to darmowe, nieoficjalne narzędzie dla graczy Marvel Strike Force, udostępniane „tak jak jest”, bez żadnych gwarancji.

  • Aplikacja tylko odczytuje dane z oficjalnego MSF API za Twoją zgodą i nie wykonuje akcji w grze w Twoim imieniu.
  • Dane z API mogą być niekompletne lub nieaktualne; API jest w wersji beta i może się zmienić.
  • Marvel Strike Force jest znakiem towarowym Scopely, Inc. i Marvel. Aplikacja nie jest z nimi powiązana.
